# Source catalogs

These CSV files are generated by `scripts/catalog-source-assets.mjs`.

- `ANIMATION_CATALOG.csv` inventories the local FBX archive and marks every
  entry `license-review-required`.
- `TEXTURE_CATALOG.csv` inventories the shipped texture files and points back
  to the authoritative provenance manifest.

Catalogs are reviewable evidence; they do not grant permission to redistribute
the source binaries they describe.
