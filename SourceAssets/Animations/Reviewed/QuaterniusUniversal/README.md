Both source pages and both included license files declare CC0 1.0. The free
Standard archives contain 43 animation clips each, including one `A_TPose`
clip per pack. The tracked catalog records all 86 source clips. The browser
export selects 29 motions with implemented city or character uses and excludes
combat, weapon, death, magic, swimming, and duplicate bind-pose content.

The local archives and unmodified source GLBs live under the ignored
`SourceAssets/Animations/Raw/Verified/Quaternius/` workspace. They are not
republished as a raw catalogue dump. `scripts/convert-quaternius-hero.py`
combines the reviewed clips with the matching 65-joint Male Ranger outfit.
