# Texture workspace

The current production textures are the curated 1K CC0 maps under
`public/textures/`. They are recorded in
`docs/Assets/ASSET_MANIFEST.csv` and are not duplicated here.

Use `Raw/` for newly acquired authoring maps and `Working/` for edited sources.
An optimized texture moves to `public/textures/` only when executable source
references it and its provenance row is complete.
